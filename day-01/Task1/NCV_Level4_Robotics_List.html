1. Creating a Python list

🧩 Skill 1: Put related information into one container.

A list stores multiple values in one variable.

Think of a shopping list. Instead of creating a separate variable for every item, keep all the items together in one list.

General syntax

list_name = [item1, item2, item3]
  • The list name follows normal variable naming rules.
  • Square brackets [ ] mark the beginning and end of a list.
  • Items are separated by commas.
  • Text values must be placed inside quotation marks.

List of text (strings)

sensors = ["ultrasonic", "infrared", "touch"]

List of numbers

motor_speeds = [40, 60, 80]

What does the list look like?

For sensors = ["ultrasonic", "infrared", "touch"]:

Index 0ultrasonicfirst item
Index 1infraredsecond item
Index 2touchthird item
Remember: Python starts counting list positions at 0, not 1. The first item is index 0.

2. Output, access and modify list values

🔎 Skill 2: Find the value you need, then update it safely.

Index = numbered drawer. If you want the value in a particular drawer, use its index inside square brackets.

Access a value

motor_speeds = [40, 60, 80] print(motor_speeds[0]) # displays 40 print(motor_speeds[2]) # displays 80
The general pattern is list_name[index].

Change (assign) a value

motor_speeds = [40, 60, 80] motor_speeds[1] = 75 print(motor_speeds) # Output: [40, 75, 80]

The equals sign assigns a new value to the selected position. It replaces the old value.

3. Adding items to a list

➕ Skill 3: Give your robot new information.

append()

Adds one item to the end of a list.

components = ["motor", "wheel"] components.append("sensor") print(components) # ['motor', 'wheel', 'sensor']
Append = join the back of the queue.

insert()

Adds one item at a chosen index.

components = ["motor", "wheel"] components.insert(1, "sensor") print(components) # ['motor', 'sensor', 'wheel']
Insert = choose a specific place in the queue.
Remember the brackets: append(value) needs the value. insert(index, value) needs both the position and the value, in that order.

4. Removing items from a list

🧹 Skill 4: Remove the right item using the right command.

Three ways to remove – know the difference!

MethodRemovesExample
delItem at a specific indexdel parts[1]
pop()Last item by default; returns the removed itemremoved = parts.pop()
remove()First matching valueparts.remove("wheel")

1. del – delete by position

parts = ["motor", "wheel", "sensor"] del parts[1] print(parts) # ['motor', 'sensor']

Index 1 is removed. You do not need brackets after del beyond the list subscript.

2. pop() – remove and keep

parts = ["motor", "wheel", "sensor"] last_part = parts.pop() print(last_part) # sensor print(parts) # ['motor', 'wheel']

The removed item is stored in last_part. You can also use pop(index) to remove a chosen position.

3. remove() – remove by value

parts = ["motor", "wheel", "sensor"] parts.remove("wheel") print(parts) # ['motor', 'sensor']

You give remove() the value, not its index. It removes the first matching value.

Important differences: del parts[1] uses an index. parts.remove("wheel") uses a value. parts.pop() removes an item and gives it back so you can assign it to a variable.

5. Sorting a list

📊 Skill 5: Put information in a useful order.

Imagine arranging robot component labels alphabetically. Sorting puts values into order so they are easier to read and process.

sort() – permanent

Changes the original list order.

speeds = [80, 40, 60] speeds.sort() print(speeds) # [40, 60, 80]
ORIGINAL LIST CHANGES

sorted() – temporary result

Returns a new sorted list. The original list stays in its old order.

speeds = [80, 40, 60] ordered = sorted(speeds) print(ordered) # [40, 60, 80] print(speeds) # [80, 40, 60]
ORIGINAL LIST STAYS THE SAME

Ascending and descending order

speeds.sort() # ascending: low to high speeds.sort(reverse=True) # descending: high to low ordered = sorted(speeds) # new ascending list ordered = sorted(speeds, reverse=True) # new descending list

6. Finding the length of a list

🔢 Skill 6: Count how many values your list contains.

len() is a counting tool. It tells you how many items are inside the list – not the index of the last item.

Syntax and example

sensors = ["ultrasonic", "infrared", "touch"] count = len(sensors) print(count) # Output: 3

Use len(list_name). The answer is the total number of items.

Length versus index

Index 010
Index 120
Index 230
Length3three items

This list has a length of 3, but its last valid index is 2.
